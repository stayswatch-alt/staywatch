# Stay Watch

Инструмент для документирования вредоносного контента, направленного против участников Stray Kids. Состоит из двух частей:

- **Публичная форма** (`/`) — открыта для всего фандома, только отправка репортов. Нет доступа на чтение/удаление чужих данных.
- **Панель модератора** (`/admin`) — закрыта паролем (Supabase Auth), полный список, статусы, фильтры, экспорт.

Дубли (один и тот же URL зарепортили много раз) не создают новых строк — вместо этого увеличивается счётчик `report_count` у существующей записи. Есть базовая защита от ботов (honeypot-поле).

Стек: React + Vite + Supabase.

## 1. Настройка Supabase — база данных и хранилище файлов

1. Зайди в свой Supabase-проект → **SQL Editor**.
2. Выполни содержимое `supabase/schema.sql` целиком — это создаст таблицу `incidents`, функцию `submit_incident()` и бакет `screenshots` со всеми политиками доступа.
   - Если таблица `incidents` уже существует из старой версии — сначала выполни миграционные строки, указанные в комментарии в начале файла.
3. Открой **Project Settings → API Keys**, скопируй `Project URL` и **Publishable key**.

Проверить, что бакет создался: **Storage → screenshots** должен появиться в списке (public).

## 2. Настройка Supabase — доступ модераторов

Модераторы входят по email + паролю через Supabase Auth. Добавь их вручную:

1. **Authentication → Users → Add user**
2. Введи email и пароль для каждого модератора (можно поставить "Auto Confirm User", чтобы не настраивать отправку писем)
3. Готово — этими данными модератор входит на `/admin`

## 3. Локальный запуск

```bash
cd stay-watch
npm install
cp .env.example .env.local
```

Впиши в `.env.local`:
```
VITE_SUPABASE_URL=https://your-project-ref.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_...
```

```bash
npm run dev
```

- Публичная форма: `http://localhost:5173/`
- Панель модератора: `http://localhost:5173/admin`

## 4. Деплой (Vercel) — важно для маршрутизации

Это одностраничное приложение без роутинг-библиотеки — переход между `/` и `/admin` определяется просто по `window.location.pathname`. При статическом деплое (Vercel и т.п.) нужно, чтобы сервер отдавал `index.html` для любого пути, иначе прямой переход на `/admin` даст 404.

Для Vercel — добавь `vercel.json` в корень проекта:
```json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
```

## Как это защищено

- Таблица `incidents` закрыта RLS-политикой: читать/менять/удалять могут только авторизованные (модераторы).
- Публичная форма никогда не читает и не пишет в таблицу напрямую — она вызывает функцию `submit_incident()` (security definer), которая либо создаёт новую запись, либо увеличивает счётчик у существующей по тому же URL.
- Скриншоты загружаются сразу в форме (до 3 файлов, до 10MB каждый) в публичный бакет `screenshots` — загружать туда файлы может любой, удалять их может только модератор.
- Скрытое honeypot-поле в форме отсеивает часть автоматического спама.
